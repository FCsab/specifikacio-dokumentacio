The Specification Editor Book

A complete guide to the ELTE Specification Editor (progalap.elte.hu/specifikacio), the tool used for specifications in the course PROGRAMMING (IP-18fPROGEG). It covers every block, type and programming theorem, and has worked course tasks. Every example is checked automatically, so you can copy it and expect the same result.

Use speci-local

speci-local is an offline Specification Editor for Linux and Windows. It accepts the same specifications as the ELTE editor and needs no login or network. It evaluates as you type, and its error messages say what is wrong and how to fix it. Download it or read how to use it.

An example

A specification, and a test case that the editor evaluates against it:

In: n∈N, nums∈N[1..n]
Out: cnt∈N
Pre: -
Post: cnt=COUNT(i=1..n, nums[i] mod 2 = 1)
n: 5
nums: [3, 72, 81, 4, 5]
cnt: 3

The book starts from exactly this example and works up to compound tasks.

A Specifikációszerkesztő könyve

Teljes útmutató az ELTE Specifikációszerkesztőhöz (progalap.elte.hu/specifikacio), amellyel a Programozás alapjai (IP-18fPROGEG) tárgyban a specifikációkat írjuk. Minden blokkot, típust és programozási tételt bemutat, és kidolgozott tárgyi feladatokat is tartalmaz. Minden példát automatikusan ellenőrzünk, így bemásolhatod, és ugyanazt az eredményt kapod.

Használd a speci-localt

A speci-local offline Specifikációszerkesztő Linuxra és Windowsra. Ugyanazokat a specifikációkat fogadja el, mint az ELTE-s szerkesztő, és nem kell hozzá se bejelentkezés, se hálózat. Gépelés közben értékel, a hibaüzenetei pedig megmondják, mi a hiba, és hogyan javítsd. Töltsd le, vagy olvasd el, hogyan kell használni.

Egy példa

Egy specifikáció, és egy teszteset, amelyre a szerkesztő kiértékeli:

Be: n∈N, szamok∈N[1..n]
Ki: db∈N
Ef: -
Uf: db=DARAB(i=1..n, szamok[i] mod 2 = 1)
n: 5
szamok: [3, 72, 81, 4, 5]
db: 3

A könyv pontosan ezzel a példával indul, és eljut az összetett feladatokig.
