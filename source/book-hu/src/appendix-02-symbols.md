# B. függelék: Jelek és billentyűparancsok

## Különleges karakterek

| Jel | Neve | Online szerkesztő | speci-local | ASCII / szóalak |
|:---:|------|-------------------|-------------|-----------------|
| `∈` | eleme | Insert gomb | <kbd>Alt</kbd>+<kbd>1</kbd> | `in`*, `eleme`* |
| `∀` | minden | Insert gomb | <kbd>Alt</kbd>+<kbd>2</kbd> | `forall`, `minden`* |
| `∃` | létezik | Insert gomb | <kbd>Alt</kbd>+<kbd>3</kbd> | `exists`, `létezik`* |
| `≠` | nem egyenlő | Insert gomb | <kbd>Alt</kbd>+<kbd>4</kbd> | `!=`, `<>`* |
| `≤` | kisebb vagy egyenlő | Insert gomb | <kbd>Alt</kbd>+<kbd>5</kbd> | `<=` |
| `≥` | nagyobb vagy egyenlő | Insert gomb | <kbd>Alt</kbd>+<kbd>6</kbd> | `>=` |
| `->` | implikáció | | | (nincs jele; a `→`-t nem fogadja el) |
| `¬` | nem | | | `not`, `nem` |
| | és, vagy | | | `and`, `or`, `és`, `vagy` (a `∧`-t és a `∨`-t nem fogadja el) |

\* csak az online szerkesztőben.

> [!TIP]
> Linuxon compose billentyűvel is beírhatod ezeket a jeleket, és bármilyen
> rendszeren kimásolhatod őket ebből a táblázatból. A gyakorlatban az ASCII
> alakok a leggyorsabbak, és mindenhol elfogadottak.

## Online szerkesztő

| Billentyű | Művelet |
|-----------|---------|
| <kbd>S</kbd> / <kbd>D</kbd> / <kbd>V</kbd> / <kbd>H</kbd> gombok | a Specification, Data, Visualization, History panel megjelenítése/elrejtése |
| <kbd>Shift</kbd>+<kbd>Space</kbd>, majd <kbd>Tab</kbd> | teszteset-sablon beszúrása (a Data panelben) |
| <kbd>←</kbd> / <kbd>→</kbd> | lépés vissza / előre a léptetőben |

## speci-local

| Parancs | Művelet |
|---------|---------|
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | kiértékelés |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | új |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | megnyitás |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | mentés / mentés másként |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | a projekt másolása `SPECI1:` sorként |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | projekt beillesztése |
| <kbd>Alt</kbd>+<kbd>1</kbd>…<kbd>6</kbd> | `∈ ∀ ∃ ≠ ≤ ≥` |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Tab</kbd>/<kbd>Enter</kbd>, <kbd>Esc</kbd> | kiegészítés: választás, beszúrás, bezárás |
| <kbd>←</kbd> / <kbd>→</kbd> | léptetés a léptetőben |

## Ez a könyv

| Billentyű | Művelet |
|-----------|---------|
| <kbd>S</kbd> vagy <kbd>/</kbd> | keresés |
| <kbd>←</kbd> / <kbd>→</kbd> | előző / következő oldal |
| <kbd>Esc</kbd> | keresés bezárása |
