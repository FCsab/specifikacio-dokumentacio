# Appendix B: Symbols and keyboard shortcuts

## Special characters

| Symbol | Name | Online editor | speci-local | ASCII / word form |
|:------:|------|---------------|-------------|-------------------|
| `∈` | element of | Insert button | <kbd>Alt</kbd>+<kbd>1</kbd> | `in`*, `eleme`* |
| `∀` | for all | Insert button | <kbd>Alt</kbd>+<kbd>2</kbd> | `forall`, `minden`* |
| `∃` | there exists | Insert button | <kbd>Alt</kbd>+<kbd>3</kbd> | `exists`, `létezik`* |
| `≠` | not equal | Insert button | <kbd>Alt</kbd>+<kbd>4</kbd> | `!=`, `<>`* |
| `≤` | less or equal | Insert button | <kbd>Alt</kbd>+<kbd>5</kbd> | `<=` |
| `≥` | greater or equal | Insert button | <kbd>Alt</kbd>+<kbd>6</kbd> | `>=` |
| `->` | implies | | | (no symbol; `→` is rejected) |
| `¬` | not | | | `not`, `nem` |
| | and, or | | | `and`, `or`, `és`, `vagy` (`∧` and `∨` are rejected) |

\* only in the online editor.

> [!TIP]
> On Linux you can also type these symbols with a compose key, and on any
> system you can copy them from this table. In practice, the ASCII forms are
> the fastest to type, and they are accepted everywhere.

## Online editor

| Key | Action |
|-----|--------|
| <kbd>S</kbd> / <kbd>D</kbd> / <kbd>V</kbd> / <kbd>H</kbd> buttons | show/hide the Specification, Data, Visualization, History panes |
| <kbd>Shift</kbd>+<kbd>Space</kbd>, then <kbd>Tab</kbd> | insert a test case template (in the Data pane) |
| <kbd>←</kbd> / <kbd>→</kbd> | step backward / forward in the Stepper |

## speci-local

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | evaluate |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | new |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | open |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | save / save as |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | copy the project as a `SPECI1:` line |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | paste a project |
| <kbd>Alt</kbd>+<kbd>1</kbd>…<kbd>6</kbd> | `∈ ∀ ∃ ≠ ≤ ≥` |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Tab</kbd>/<kbd>Enter</kbd>, <kbd>Esc</kbd> | choose, insert, close completion |
| <kbd>←</kbd> / <kbd>→</kbd> | step in the stepper |
