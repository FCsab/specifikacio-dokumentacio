# Saving and sharing

## Saving

1. Give the specification a name in the **task name** field at the top of the
   window (for example *OddCount*).
2. Click **Save**.

The specification and all of its test cases are stored on the ELTE server.
Saving changes the page address: it now contains a unique identifier.

```text
https://progalap.elte.hu/specifikacio/v1/?uuid=058de53d-56cd-4733-93f1-8f4cf2212a86
```

This address is a *permanent link* (permalink) to the saved version.

> [!IMPORTANT]
> The **Save** button is only active once there is something to save. Save
> only a specification without errors: one that parses and passes its tests.

## Sharing

To share your work, for example to submit it or to ask a teacher for help,
copy the address from the browser's address bar after saving and send it. Whoever
opens the link sees the specification with all its test cases and can evaluate
it.

Examples from the official course material:

| Task | Link |
|------|------|
| Selecting the first odd number | [ecacc1f7-…](https://progalap.elte.hu/specifikacio/v1/?uuid=ecacc1f7-a451-4d14-8444-8527ff11a613) |
| Counting odd numbers | [058de53d-…](https://progalap.elte.hu/specifikacio/v1/?uuid=058de53d-56cd-4733-93f1-8f4cf2212a86) |
| Search that fails | [3cacade4-…](https://progalap.elte.hu/specifikacio/v1/?uuid=3cacade4-7c80-451e-9e62-610baa01b68b) |

(You need to be logged in to open them.)

## History

Each save creates a new version. The <kbd>H</kbd> button opens the History pane,
where you can go back to earlier saved versions of the specification.

## New specification

**New** clears the editor for a new task. Save the current one first if you
want to keep it.

> [!TIP]
> To keep a copy on your own computer, or to share a specification without
> the ELTE login, use [speci-local](ch10-03-files.md). It saves to plain `.sp`
> files and can copy a whole project, tests included, as a single line of text.
